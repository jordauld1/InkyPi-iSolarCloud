## Findings considered and rejected

- **Plaintext password in the login body**: this is the documented V1
  "plaintext" Open API mode, it goes over HTTPS, and the README states it.
  Not a defect.
- **Logging in on every refresh, no token cache**: documented in the README,
  and harmless at e-ink refresh rates.
- **`x-access-key` header carries the secret**: the API requires it.
- **History wiped on `inkypi plugin install`**: InkyPi's installer runs
  `rm -rf` on the plugin folder. Only the current day's chart is lost, and
  plan 009 addresses the root cause if it goes ahead.
- **Battery SOC `* 100` multiplier**: assumed correct (the API returns a
  fraction). Plan 003 has a STOP condition in case that's wrong.
